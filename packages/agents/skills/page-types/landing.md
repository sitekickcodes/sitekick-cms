Typical order: hero with the promise and the main action; the problem or need in the reader's words; how it works (three steps or features); proof (stats, a quote, logos); answers to objections (FAQ: price, time, risk); closing call to action that repeats the main action.

Keep it about one offer. If the page sells two things, it is two pages.
